## Installation
To run this portfolio website locally, follow these steps:

```bash
git clone https://github.com/Kamau-Johnson/your-portfolio-repo.git
cd your-portfolio-repo
npm install
npm run dev
```

Then open your browser and go to http://localhost:3000 to view the website.
## Deployment

To deploy this project, run the following command:

```bash
  npm run deploy
```

## Lessons Learned

Building this portfolio website helped me deepen my understanding of Next.js and to setup it's environment when using the stack particularly in creating dynamic and responsive user interfaces with Tailwind CSS. I improved my skills in structuring a modern web application and managing component-based design effectively.

One of the challenges I faced was optimizing the site for both performance and aesthetics across different devices. I overcame this by learning and applying best practices in responsive design and code optimization, ensuring a smooth user experience on desktops, tablets, and mobiles.
